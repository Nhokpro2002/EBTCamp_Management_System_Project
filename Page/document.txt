1️⃣ Tính năng cốt lõi – quản lý dữ liệu cơ bản (Must-have)

Đây là những thứ không thể thiếu, nếu không hệ thống sẽ không vận hành được.

a) Quản lý sản phẩm (Product Management)
Thông tin cơ bản:
Mã sản phẩm (SKU)
Tên sản phẩm
Mô tả
Đơn vị tính (cái, kg, lít…)
Giá nhập, giá bán (nếu cần)
Hình ảnh (tuỳ chọn)
Tính năng:
Thêm / sửa / xóa sản phẩm
Tìm kiếm sản phẩm theo mã hoặc tên
Tại sao ưu tiên: không có danh sách sản phẩm, không thể nhập xuất hàng.
b) Quản lý kho / vị trí lưu trữ (Warehouse / Location Management)
Thông tin:
Mã kho / tên kho
Vị trí: kệ, ngăn, kho nhỏ
Tính năng:
Thêm / sửa / xóa kho
Quản lý vị trí lưu trữ (optional cho lần đầu có thể để đơn giản)
Ưu tiên: Nếu kho lớn, quản lý vị trí giúp kiểm soát chính xác tồn kho.
c) Quản lý tồn kho (Inventory Management)
Thông tin:
Số lượng hiện có
Vị trí lưu trữ (kho/kệ)
Hạn sử dụng (nếu là hàng thực phẩm / dược phẩm)
Tính năng:
Nhập kho: tăng số lượng
Xuất kho: giảm số lượng
Điều chỉnh tồn kho (khi kiểm kho)
Ưu tiên: Đây là core của WMS – không có tồn kho chính xác, các quyết định sau này sẽ sai.
d) Quản lý nhập xuất (Inbound / Outbound)
Nhập kho (Purchase / Receipt)
Chọn sản phẩm
Nhập số lượng
Ghi chú ngày nhập, nhà cung cấp
Xuất kho (Delivery / Shipment)
Chọn sản phẩm
Xuất số lượng
Ghi chú ngày xuất, khách hàng
Ưu tiên: Cần cho hoạt động hàng ngày; không thể làm kho mà không nhập xuất.
e) Dashboard / Báo cáo cơ bản
Thông tin:
Tổng số sản phẩm
Sản phẩm tồn kho thấp
Nhập/xuất trong ngày
Ưu tiên: Giúp người quản lý nhìn thấy tình trạng kho ngay.

    connector: kiểu đường nối mặc định (Bezier, Flowchart, Straight)
    endpoint: kiểu điểm nối mặc định
    paintStyle: style mặc định của đường nối
    hoverPaintStyle: style khi hover
    maxConnections: số connection tối đa mỗi node*/

    jsPlumb.getInstance({
  Connector: ["Flowchart"],
  Endpoint: "Dot",
  PaintStyle: { stroke: "blue", strokeWidth: 2 },
  HoverPaintStyle: { stroke: "red" },
  ConnectionOverlays: [
    ["Arrow", { location: 1 }]
  ]
});

2. Endpoint (điểm nối)
Bạn có thể custom:
type: Dot, Rectangle, Blank
radius
fill, stroke
hoverStyle
isSource, isTarget
anchor: vị trí neo (Top, Bottom, Continuous, Perimeter…)

3. Connector (đường nối)
Các thuộc tính thường dùng:
type:
"Straight"
"Bezier"
"Flowchart"
"StateMachine"

cssClass
strokeWidth, strokeColor

4. Overlay (thành phần trên đường nối)
Bạn có thể thêm:
Arrow (mũi tên)
Label (text)
Custom HTML overlay
overlays: [
  ["Label", { label: "A → B", location: 0.5 }],
  ["Arrow", { location: 1, width: 10, length: 10 }]
]

5. Connection-level customization (quan trọng nhất)
Khi tạo connection, bạn có thể override toàn bộ:
paintStyle
hoverPaintStyle
detachable
reattach
editable
type
overlays
parameters (custom data của bạn)

jsPlumb.connect({
  source: "A",
  target: "B",
  paintStyle: { stroke: "green", strokeWidth: 3 },
  detachable: true,
  parameters: {
    id: "conn-1",
    status: "active"
  }
});

6. Custom data (parameters)
Một điểm rất hay:
Bạn có thể gắn bất kỳ dữ liệu nào:
parameters: {
  userId: 123,
  rule: "approve",
  weight: 0.8
}

Sau đó lấy lại khi xử lý event:
instance.bind("connection", function(info) {
  console.log(info.connection.getParameters());
});


1. Nhóm tạo & quản lý connection
connect()
Tạo đường nối giữa 2 node:
instance.connect({
  source: "A",
  target: "B"
});

deleteConnection()
Xóa 1 connection cụ thể:
instance.deleteConnection(conn);

detach()
Tách connection giữa 2 điểm:
instance.detach(conn);

2. Nhóm quản lý node (element)
remove()
Xóa node khỏi canvas:
instance.remove("nodeId");

repaint()
Vẽ lại toàn bộ layout:
instance.repaintEverything();

revalidate()
Cập nhật vị trí connection khi node thay đổi:
instance.revalidate("nodeId");

3. Nhóm cấu hình source/target
makeSource()
Biến node thành điểm bắt đầu nối:
instance.makeSource(el, options);

makeTarget()
Biến node thành điểm nhận nối:
instance.makeTarget(el, options);


unmakeSource() / unmakeTarget()
Gỡ khả năng nối:
instance.unmakeSource(el);
instance.unmakeTarget(el);

4. Nhóm event (rất quan trọng)
bind()
Lắng nghe sự kiện:
instance.bind("connection", function(info) {
  console.log(info.sourceId, info.targetId);
});

Các event phổ biến:
connection
connectionDetached
connectionMoved
beforeDrop

5. Nhóm lấy dữ liệu graph
getAllConnections()
Lấy toàn bộ connection:
instance.getAllConnections();

getConnections()
Lấy connection của 1 node:
instance.getConnections("A");

6. Nhóm drag & layout
draggable()
Bật kéo thả node:
instance.draggable("nodeId");

setContainer()
Đổi container:
instance.setContainer("canvas");

7. Nhóm nâng cao (parameters & metadata)
setParameter() / getParameter()
instance.setParameter("mode", "edit");

Connection parameters:
conn.getParameters();
